# Where these tables come from

The app's own code is MIT (see `LICENSE` at the repo root). The files here are not all ours.

## From palworld-save-pal (GPL v3)

Synced as-is from [palworld-save-pal](https://github.com/oMaN-Rod/palworld-save-pal) releases by
`scripts/datagen/sync_game_data.py`, and licensed under the GNU General Public License v3
(`LICENSE-palworld-save-pal`, copied from that project):

- `pals.json`, `items.json`, `active_skills.json`, `passive_skills.json`, `buildings.json`,
  `elements.json`, `friendship.json`, `breeding.json`
- everything under `l10n/en/`

`map_objects.json` is generated from that project's map point data (fast travel, towers, dungeons,
predators) by `scripts/datagen/generate_map_objects.py`, so it carries the same license.

## Generated by this project from the game files

`spawns.json`, `partner_skills.json`, `pal_parameters.json`, `schematics.json`, `activity.json`,
`loadout.json`, `exp.json`, `paldeck.json` and `obtain.json` are read out of the game's pak by the
scripts in `scripts/datagen`; `map_layers.json` is kept by hand.
